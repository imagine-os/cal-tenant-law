## What changed

New exported `themeVars(theme, brand)`. Generator emits `:root, :root[data-brand="clearsky"], :root[data-brand="ctl"]` for the default and one block per brand x theme. Fix: status keys are now kebab-cased, so `--color-success-strong` (used by Badge / StatTile) exists.
