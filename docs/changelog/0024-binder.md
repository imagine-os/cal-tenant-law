# 0024 - Pass 2 wave A: the client's evidence binder (C-20, C-21, C-22) and the staff review side (L-31)

version: 0.2.0
date: 2026-09-20
prompt: 0006
intent: Build Justin's ask - "the client's ability to upload evidence, or connect their email and text messages, etc." - and the brief's binder line (gathering documents from customers, helping them keep track of all their documents). A tenant can photograph the notice on the door, upload the lease, paste the texts with the property manager, hand over a WhatsApp export or connect a mailbox after a plain-language consent step; the firm reviews what arrives, turns it into labelled exhibits with a chain of custody, asks for what is still missing and prints the exhibit index for trial. Uploading also answers the `client_requests` row that asked for it, so an order stops waiting on the client without a phone call.
decision: D-052 the binder is its own module and C-20 supersedes C-02 (one module owns `/app/binder`); evidence lands as `status = new` and only staff turn it into an exhibit with a letter (RULE-EVID-02); consent is a row, recorded before any channel is read (RULE-EVID-05); imports keep the original text verbatim and keep unparsable lines rather than dropping them (RULE-EVID-03); every item carries `captured_at` (when the thing happened) apart from `received_at`, a browser-computed SHA-256 and an append-only chain of custody (RULE-EVID-04); the objects map is 2D DOM + SVG with keyboard navigation and zoom buttons (three.js is T-076, this stays its fallback); the demo stores a small preview data URL and never the original bytes, because file storage is a Pass 3 seam (T-072).
rejected: Storing uploaded files as base64 in the row (a 60 KB preview plus a hash is enough for a demo and keeps localStorage usable); letting the client set a status or an exhibit letter (an exhibit is a legal artefact, not a self-service label); parsing imported messages into a "cleaned" summary (an import that rewrites the evidence is worthless - RULE-EVID-03); a three.js objects scene this pass (it would not be the phone view and T-076 owns it); a second BottomNav tab for C-21 (five tabs is the limit on a 360 px phone - C-20's "What is missing" strip, C-01 and C-11 link to it instead); flipping `crq_004` (Prieto's overdue envelope photo) to received, because the front-desk module demos the overdue chase on it.
