# C-03 · Client learning

## Purpose

The firm's free curriculum as a path instead of a playlist: the videos in order, what the tenant has already watched, and which one matters at their square of the board right now. The firm's own argument is "rather than pay a lawyer to tell you the same information, watch the videos" — this screen is that argument, with progress.

## Sections (layout order)

1. PageHeader.
2. Overall progress — watched / total.
3. NextUp — the lesson to watch now, with the square it explains.
4. CurriculumList — every lesson with kind, square and a progress bar.

## Data

| Table | Read / write | Notes |
| --- | --- | --- |
| `lessons` | read | ordered by `order` (Winning Your Eviction 1–7, the Eviction Series, the topic videos) |
| `lesson_progress` | read / write | `watched_pct`, `completed_at` by id; inserted when there is no row yet |
| `cases` | read | the current square, to pick what matters now |

## Rules

- `RULE-SYS-02` — the write goes through the provider by id, with `version` bumped.

## Actions (manifest)

| Id | Intent | Permission | Params | Live |
| --- | --- | --- | --- | --- |
| `client.playLesson` | play a lesson video | none | `id: id` | stub |
| `client.markLessonWatched` | mark a lesson as watched | none | `id: id` | yes |

## Logic

- Next up = the lowest-order unfinished lesson, preferring lessons whose `stage_node_id` equals the case's square.
- Marking watched writes `watched_pct = 100` and `completed_at = now`; running it twice is harmless.
