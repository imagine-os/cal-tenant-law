# Kanban

Mirrors `docs/plan/tasks.json` (statuses `done | doing | todo | blocked`); one line per task, `- T-nnn CODE title (model)`. Move a card = change the status in `tasks.json` and here in the same turn (`npm run plan:check` flags a mismatch once T-027 lands). Numbered ids are never reused. Updated 2026-09-18 (Pass 1 integration and release 0.1.0, Fable 5.1; regenerated by `npm run plan:sync`).
